# Созвездия — игровое поле для стрим-ивента

Карта звёздного неба: каждое **созвездие** — цепочка заданий, каждая **звезда** — игра из пула своей сложности.

| Сложность | Длительность | Награда за звезду |
|---|---|---|
| 🟢 Зелёная | до 4 ч | 10 ✦ |
| 🟡 Жёлтая | 4–10 ч | 20 ✦ |
| 🔴 Красная | 10–20 ч | 35 ✦ |
| 🟣 Фиолетовая | 20–40 ч | 55 ✦ |
| 🟥 Бордовая | 40+ ч | 80 ✦ |

## Правила
1. Игрок выбирает свободное созвездие. Пока не пройдены все его звёзды, новое взять нельзя.
2. Звёзды проходятся по порядку. Для текущей звезды «Крутить игру» выбирает случайную игру из пула её сложности (без повторов для игрока). Можно сделать реролл или вписать игру вручную.
3. «Пройдено» — звезда зажигается, игрок получает валюту. За всё созвездие — награда и бонус.
4. По умолчанию одно созвездие может занимать только один игрок, собранное остаётся за ним (переключается в настройках).

Все действия подсвечиваются на карте цветом игрока: баннеры, вспышки, пульсирующий маркер на текущей звезде, зажжённые линии.

## Запуск
Статический сайт без сборки: откройте `index.html` в браузере или поднимите любой статический сервер (`python3 -m http.server`). Можно выложить на GitHub Pages.

- **⚙ Настройки** — игроки, балансы, сложности, валюта, пулы игр, награды и сложности звёзд в созвездиях, экспорт/импорт JSON, сброс.
- **Режим трансляции** (клавиша `H`) — скрывает панель управления, остаётся только карта.
- **Ctrl+Z** — отмена последнего действия.

Данные хранятся в `localStorage` браузера.
